1What is a non-linear programming problem?

LP taught you to optimise a straight-line objective over a polygon. In this unit, curves enter the picture.

1.1Definition

Definition Non-Linear Programming Problem (NLPP)

An optimization problem is called non-linear if the objective function, or at least one of its constraints, is a non-linear function of the decision variables.

The general NLPP can be written as

$$\text{Optimize (max or min)}\quad z=f(x_1,x_2,\dots ,x_n)$$ $$\text{subject to}\quad g^{i}(x_1,\dots ,x_n)\ \{\le,=,\ge\}\ b_i,\quad i=1,\dots ,m,$$ $$x_j\ge 0,\quad j=1,\dots ,n.$$

If either $f$ or any $g^i$ is non-linear (has terms like $x_1^2$, $x_1x_2$, $e^{x}$, $\log x$, $\sqrt{x}$…), the problem is an NLPP.

Example (from class)

$$\max\ 4x_1+3x_2 \quad\text{s.t.}\quad x_1+x_2\le 3,\quad x_1x_2\le 1,\quad x_1,x_2\ge 0.$$

The objective is linear, but the constraint $x_1x_2\le1$ is not: its boundary $x_1x_2=1$ is a hyperbola. So this is an NLPP. Look at its feasible region:

The class notes draw two lessons from this picture:

  1. The feasible region need not be a convex set. In LP it always was.
  2. The optimum need not be at a corner point. The corner-point method and the simplex method rely on it being at a corner, so they no longer work.

Point 2 is worth seeing. In LP the objective is a flat plane, so it is always pushed to a corner of the polygon. A curved objective can have its best value inside the region:

1.3Local vs global optimum

With curves, a function can have several "peaks" and "valleys". We need words to tell them apart.

Definition Local and global optima

Let $S$ be the feasible region and $N_\delta(\bar x)$ a small neighbourhood (ball of radius $\delta$) around $\bar x$.

  • $\bar x$ is a local maximum if there is some $\delta>0$ with $f(\bar x)\ge f(x)$ for all $x\in N_\delta(\bar x)$. It beats every nearby point.
  • $\bar x$ is a local minimum if there is some $\delta>0$ with $f(\bar x)\le f(x)$ for all $x\in N_\delta(\bar x)$.
  • $x^*$ is a global maximum if $f(x^*)\ge f(x)$ for all $x\in S$. It beats every feasible point. A global minimum is defined the same way with $\le$.

A point where the slope (derivative or gradient) is zero is called a stationary or critical point. Stationary points are only candidates: each could be a max, a min, or neither. The tests in §3 and §5 tell them apart. Convexity (§2) is what lets us upgrade "local" to "global".

2Convex and concave functions

The single most important idea in this unit. Convexity decides whether a stationary point is a max or a min, and whether it is the global answer.

2.1First, convex sets

Before defining a convex function, we need the domain to be a convex set.

Definition Convex set

A set $S\subseteq\mathbb R^n$ is convex if for any two points $x,u\in S$, the entire line segment joining them lies in $S$: $$\lambda x+(1-\lambda)u\in S\qquad\text{for all }\lambda\in[0,1].$$

The expression $\lambda x+(1-\lambda)u$ is just "a point on the segment from $u$ to $x$". At $\lambda=1$ it is $x$, at $\lambda=0$ it is $u$, at $\lambda=\tfrac12$ it is the midpoint. As $\lambda$ slides from 0 to 1, the point slides from $u$ to $x$.

Don't mix these up

A function can be convex or concave. A set can only be convex (or not). There is no such thing as a "concave set".

2.2Convex functions

Definition Convex function

Let $S\subseteq\mathbb R^n$ be a convex set and $f:S\to\mathbb R$. Then $f$ is convex on $S$ if for all $x,u\in S$ and all $\lambda\in[0,1]$: $$f\big(\lambda x+(1-\lambda)u\big)\ \le\ \lambda f(x)+(1-\lambda)f(u).$$ It is strictly convex if the inequality is strict ($\lt$) whenever $x\ne u$ and $0\lt\lambda\lt1$.

What the inequality says, in pictures. Take two points $x$ and $u$ on the horizontal axis and join $(x,f(x))$ to $(u,f(u))$ by a straight line. This is the secant, or chord. Now pick any in-between point $\lambda x+(1-\lambda)u$:

  • The left side, $f(\lambda x+(1-\lambda)u)$, is the height of the curve at that point.
  • The right side, $\lambda f(x)+(1-\lambda)f(u)$, is the height of the chord at that same point. It is the same weighted average applied to the heights.

So convex means the curve never rises above its chord. Equivalently, for a differentiable function, the curve always lies above each of its tangent lines. The graph is shaped like a bowl ∪.

2.3Concave functions

Definition Concave function

Let $S\subseteq\mathbb R^n$ be a convex set and $f:S\to\mathbb R$. Then $f$ is concave on $S$ if for all $x,u\in S$ and all $\lambda\in[0,1]$: $$f\big(\lambda x+(1-\lambda)u\big)\ \ge\ \lambda f(x)+(1-\lambda)f(u).$$ It is strictly concave if the inequality is strict whenever $x\ne u$ and $0\lt\lambda\lt1$.

Everything flips. The chord lies below the curve, and every tangent lies above the curve. The graph is shaped like a dome ∩, the roof of a cave ("con-cave").

2.5Properties (class-notes list)

Rules

  1. Both convex and concave ⇔ linear. Only a straight line/plane $f(x)=a^{T}x+b$ satisfies both inequalities. There the chord is the curve, so they hold with equality.
  2. Neither is possible. E.g. $\sin x$, $\cos x$, $x^3$ on $\mathbb R$.
  3. If $f,g$ are convex on a convex set $S$, then $f+g$, $\ \alpha f\ (\alpha>0)$ and $\max\{f,g\}$ are all convex.
  4. The negative of a convex function is concave, and vice-versa.
  5. If $f,g$ are concave on $S$, then $f+g$, $\ \alpha f\ (\alpha>0)$ and $\min\{f,g\}$ are all concave.

2.6Testing convexity with the second derivative (one variable)

Checking the definition directly is painful. For twice-differentiable functions, the second derivative does it instantly. $f''$ measures how the slope changes. If the slope keeps increasing ($f''\ge0$), the curve bends upward like a bowl.

Theorem Second-derivative test for convexity

Let $S\subseteq\mathbb R$ be a convex set (an interval) and $f$ twice differentiable on $S$. Then:

Condition on $S$Conclusion
$f''(x)\ge0$ for all $x\in S$⇔$f$ is convex
$f''(x)>0$ for all $x\in S$⇒$f$ is strictly convex (converse false)
$f''(x)\le0$ for all $x\in S$⇔$f$ is concave
$f''(x)\lt0$ for all $x\in S$⇒$f$ is strictly concave (converse false)

"Converse need not be true"

$f(x)=x^4$ is strictly convex, but $f''(x)=12x^2$ equals $0$ at $x=0$. So "strictly convex" does not force $f''>0$ everywhere. Similarly $-x^4$ is strictly concave with $f''(0)=0$. The arrows for the strict cases point one way only.

Quick checks. $e^x$: $f''=e^x>0$, so strictly convex. $\log x$: $f''=-1/x^2\lt0$ on $x>0$, so strictly concave. $x^3$: $f''=6x$ changes sign, so neither. $x^4-2x^2$: $f''=12x^2-4$ changes sign at $x=\pm1/\sqrt3$, so neither.

For functions of several variables, $f''$ is replaced by a matrix of second derivatives, the Hessian, and "$\ge0$" becomes "positive semi-definite". That is §4. First we use $f''$ to find optima.

3Unconstrained optimization: one variable

Problem: maximise or minimise $f(x)$ with no constraints. This is school calculus, made rigorous.

3.1Necessary condition

At the top of a peak or the bottom of a valley the curve is momentarily flat: the tangent is horizontal. So:

Necessary condition

If $x^*$ is a local maximum or minimum of a differentiable $f$, then $$f'(x^*)=0.$$

It is only necessary. Every optimum satisfies it, but so do points that are not optima, like the inflection point of $x^3$ at $0$. Solving $f'(x)=0$ gives the candidates (stationary points).

3.2Sufficient condition: the second-derivative test

Sufficient conditions

Let $f'(x^*)=0$.

  1. If $f''(x^*)>0$, then $x^*$ is a local minimum. The curve bends up (∪) there.
  2. If $f''(x^*)\lt0$, then $x^*$ is a local maximum. The curve bends down (∩) there.
  3. If $f''(x^*)=0$, no conclusion. $x^*$ could be a max, a min, or an inflection point. Use the higher-order test below.

3.3Higher-order derivative test (when $f''=0$)

Rule

Suppose $f'(x_0)=f''(x_0)=\dots=f^{(n-1)}(x_0)=0$ but $f^{(n)}(x_0)\neq0$. In words, the first non-zero derivative is the $n$-th one. Then:

  • If $n$ is odd, $x_0$ is a point of inflection (neither max nor min).
  • If $n$ is even: $f^{(n)}(x_0)>0$ gives a minimum, and $f^{(n)}(x_0)\lt0$ gives a maximum.

Why: near $x_0$, Taylor's theorem gives $f(x)-f(x_0)\approx \frac{f^{(n)}(x_0)}{n!}(x-x_0)^n$. For even $n$, $(x-x_0)^n\ge0$ on both sides, so $f$ stays on one side of $f(x_0)$: an extremum. For odd $n$, $(x-x_0)^n$ changes sign, so $f$ crosses $f(x_0)$: an inflection.

3.4From local to global

Theorem Convexity gives global optima

Let $f'(x_0)=0$.

  • If $f$ is convex (on its whole domain), $x_0$ is a point of global minimum.
  • If $f$ is concave, $x_0$ is a point of global maximum.

Locally: $x_0$ is a local max when $f$ is concave around $x_0$ ($f''\lt0$ near it), and a local min when $f$ is convex around $x_0$ ($f''>0$ near it).

The reason: a convex function lies above all its tangents. The tangent at $x_0$ is the flat line $y=f(x_0)$, so $f(x)\ge f(x_0)$ everywhere.

If $x$ is restricted to an interval $[a,b]$

Also compute $f$ at the end-points: compare $f(x^*)$, $f(a)$ and $f(b)$. The largest is the global max on $[a,b]$ and the smallest is the global min. An end-point can win even though $f'\neq0$ there.

Procedure

  1. Compute $f'(x)$, solve $f'(x)=0$ for the stationary points.
  2. Compute $f''(x)$ at each one and apply 3.2. If $f''=0$, keep differentiating (3.3).
  3. Decide global vs local: is $f$ convex/concave everywhere? ($f''\ge0$ or $\le0$ for all $x$.)

4The matrix toolkit: Hessian, minors, definiteness

With $n$ variables there is no single "$f''$". There is a whole matrix of second derivatives. This section shows how to read a sign ("positive" or "negative") off a matrix.

4.1Gradient and Hessian

Definition Gradient vector

For $f(x_1,\dots,x_n)$, the gradient is the column vector of first partial derivatives: $$\nabla f=\begin{bmatrix}\dfrac{\partial f}{\partial x_1} & \dfrac{\partial f}{\partial x_2} & \cdots & \dfrac{\partial f}{\partial x_n}\end{bmatrix}^{T}.$$ It points in the direction of steepest increase of $f$.

Definition Hessian matrix

Let $S\subseteq\mathbb R^n$ be convex and $f:S\to\mathbb R$ twice differentiable. The Hessian of $f$ is the $n\times n$ matrix of second partial derivatives: $$H_f(x)=\begin{bmatrix} \dfrac{\partial^2 f}{\partial x_1^2} & \dfrac{\partial^2 f}{\partial x_1\partial x_2} & \cdots & \dfrac{\partial^2 f}{\partial x_1\partial x_n}\\[2mm] \dfrac{\partial^2 f}{\partial x_2\partial x_1} & \dfrac{\partial^2 f}{\partial x_2^2} & \cdots & \dfrac{\partial^2 f}{\partial x_2\partial x_n}\\ \vdots & \vdots & \ddots & \vdots\\ \dfrac{\partial^2 f}{\partial x_n\partial x_1} & \dfrac{\partial^2 f}{\partial x_n\partial x_2} & \cdots & \dfrac{\partial^2 f}{\partial x_n^2} \end{bmatrix}_{n\times n}$$ Since $\dfrac{\partial^2 f}{\partial x_i\partial x_j}=\dfrac{\partial^2 f}{\partial x_j\partial x_i}$ for smooth functions, $H_f$ is symmetric.

Example (class)

$f=x_1^2+(x_2-2)^2$. Then $\nabla f=\begin{bmatrix}2x_1\\ 2(x_2-2)\end{bmatrix}$ and $H_f=\begin{bmatrix}\partial^2f/\partial x_1^2 & \partial^2f/\partial x_1\partial x_2\\ \partial^2f/\partial x_2\partial x_1 & \partial^2f/\partial x_2^2\end{bmatrix}=\begin{bmatrix}2&0\\0&2\end{bmatrix}.$

A three-variable one: $f=x_1^2+2x_2^2+x_3^2+x_1x_2-2x_3-7x_1+12$ gives $H_f=\begin{bmatrix}2&1&0\\1&4&0\\0&0&2\end{bmatrix}$.

Shortcut for quadratic functions

Almost every exam function is quadratic. For these the Hessian is a constant matrix (no $x$'s left), and you can write it down at sight:

  • a term $a\,x_i^2$ contributes $2a$ to the diagonal entry $(i,i)$;
  • a term $c\,x_ix_j$ contributes $c$ to both entries $(i,j)$ and $(j,i)$;
  • linear terms and constants contribute nothing.

E.g. $4x_1^2+2x_2^2+x_3^2-4x_1x_2\ \Rightarrow\ H=\begin{bmatrix}8&-4&0\\-4&4&0\\0&0&2\end{bmatrix}$.

4.3Definiteness: the "sign" of a matrix

For a symmetric matrix $H$ and a vector $y$, the number $y^{T}Hy$ is called a quadratic form. For $2\times2$, $y^{T}\begin{bmatrix}a&b\\b&c\end{bmatrix}y=a y_1^2+2b\,y_1y_2+c\,y_2^2$. Definiteness asks: is this number always positive, always negative, or does it depend on $y$?

Definition Definiteness

A symmetric $n\times n$ matrix $H$ is

  • positive definite (PD) if $y^{T}Hy>0$ for all $y\neq0$;
  • positive semi-definite (PSD) if $y^{T}Hy\ge0$ for all $y$;
  • negative definite (ND) if $y^{T}Hy\lt0$ for all $y\neq0$;
  • negative semi-definite (NSD) if $y^{T}Hy\le0$ for all $y$;
  • indefinite if $y^{T}Hy$ is positive for some $y$ and negative for others.

Examples: $\begin{bmatrix}2&0\\0&3\end{bmatrix}$ gives $2y_1^2+3y_2^2>0$, so PD. $\begin{bmatrix}1&0\\0&-1\end{bmatrix}$ gives $y_1^2-y_2^2$, which is positive at $(1,0)$ and negative at $(0,1)$, so indefinite.

5Unconstrained optimization: several variables

Same two-step idea as §3: set the slope to zero, then check the curvature. Slope becomes the gradient and curvature becomes the Hessian.

5.1Necessary condition

Necessary condition

If $x^*=(x_1^*,\dots,x_n^*)$ is a local max or min of $f$, then $$\nabla f(x^*)=\mathbf 0,\qquad\text{i.e.}\qquad \frac{\partial f}{\partial x_1}=\frac{\partial f}{\partial x_2}=\dots=\frac{\partial f}{\partial x_n}=0\ \text{ at }x^*.$$

This gives $n$ equations in $n$ unknowns. Their solutions are the stationary (critical) points.

5.2Sufficient condition

Sufficient conditions

Let $\nabla f(x^*)=0$ and evaluate the Hessian at $x^*$:

  • $H_f(x^*)$ positive definite ⇒ $x^*$ is a local minimum.
  • $H_f(x^*)$ negative definite ⇒ $x^*$ is a local maximum.
  • $H_f(x^*)$ indefinite ⇒ $x^*$ is a saddle point: a min in some directions, a max in others, so neither.
  • $H_f(x^*)$ only semi-definite ⇒ the test is inconclusive at that point.

Global version: if $H_f(x)$ is PD/PSD throughout the domain (so $f$ is convex), any stationary point is a global minimum. If $H_f$ is ND/NSD throughout ($f$ concave), any stationary point is a global maximum.

5.3Worked examples

  2. Write the Hessian $H_f$. Compute its leading principal minors (and principal minors if needed).

6Equality constraints: Lagrange multipliers

Now the variables must satisfy equations like $x_1+x_2+x_3=11$. The method of Lagrange multipliers turns this back into a "set the derivatives to zero" problem.

6.1The Lagrangian, and why it works

Consider

$$\text{Optimize } f(x_1,x_2)\quad\text{subject to}\quad g(x_1,x_2)=b\qquad\Big(\text{equivalently } h(x_1,x_2)=g(x_1,x_2)-b=0\Big).$$

We can't just solve $\nabla f=0$: the free optimum of $f$ is usually not on the curve $g=b$. Imagine walking along the constraint curve and watching the value of $f$. The level curves $f=c$ cross your path. At the best point on the path, the level curve you are on just touches the constraint curve without crossing it. If it crossed, you could keep walking and do better.

When two curves touch, they share a tangent line, so their perpendiculars (gradients) are parallel:

$$\nabla f=\lambda\,\nabla g\quad\text{for some number }\lambda.$$

Lagrange packaged this into one function:

Definition Lagrangian function

$$L(x_1,x_2,\lambda)=f(x_1,x_2)-\lambda\big[g(x_1,x_2)-b\big]=f-\lambda h,$$

where $\lambda\in\mathbb R$ is the Lagrange multiplier. For an equality constraint it can be positive, negative or zero.

6.2Necessary conditions

Necessary optimality conditions

At a constrained optimum, $\nabla L=\mathbf0$: $$\frac{\partial L}{\partial x_1}=\frac{\partial f}{\partial x_1}-\lambda\frac{\partial g}{\partial x_1}=0,\qquad \frac{\partial L}{\partial x_2}=\frac{\partial f}{\partial x_2}-\lambda\frac{\partial g}{\partial x_2}=0,\qquad \frac{\partial L}{\partial\lambda}=-\big(g(x)-b\big)=0.$$ The first two say $\nabla f=\lambda\nabla g$. The last one just gives back the constraint $g=b$.

With $m$ constraints $g_i(x)=b_i$ ($i=1,\dots,m$, with $m\lt n$), use one multiplier per constraint:

$$L(x,\lambda)=f(x)-\sum_{i=1}^{m}\lambda_i\big[g_i(x)-b_i\big],\qquad \frac{\partial L}{\partial x_j}=0\ (j=1..n),\qquad \frac{\partial L}{\partial \lambda_i}=0\ (i=1..m).$$

That is $n+m$ equations in $n+m$ unknowns ($x_1..x_n,\lambda_1..\lambda_m$). A solution $(x_0,\lambda_0)$ is a stationary point of $L$.

Solving trick that works almost every time

In exam problems each $\partial L/\partial x_j=0$ is linear. Express every $x_j$ in terms of the $\lambda$'s, then substitute into the constraint(s). One constraint gives one equation for $\lambda$; two constraints give two equations for $\lambda_1,\lambda_2$.

What λ means

$\lambda$ measures how fast the optimal value changes when you relax the constraint: $\lambda=\partial z^*/\partial b$. It is the "shadow price" of the resource $b$, just like dual variables in LP. In the circle example, $z^*(b)=b^2/2$ gives $dz^*/db=b=4$ at $b=4$, which is exactly $\lambda=4$.

6.3Sufficient conditions: bordered Hessian (one constraint)

The necessary conditions find candidates. To decide max vs min we need second derivatives, but only in directions that stay on the constraint. The ordinary Hessian looks in all directions, including those that leave the constraint surface, so it can give the wrong answer. Bordering it with the constraint's gradient restricts the test to the allowed directions.

Definition Bordered Hessian, n variables, 1 constraint

With $L=f-\lambda h$, $h=g-b$, evaluated at the stationary point:

Watch out: a sign typo in the notes and the textbook

Your class notes and the textbook state the maximum condition as "alternating, starting with $(-1)^{m+n}$". Read literally, this contradicts their own one-constraint rule. With $n=2,\ m=1$ it gives $(-1)^3$ (negative), yet the one-constraint rule says $D_3>0$ for a max. The correct starting sign is $\boldsymbol{(-1)^{m+1}}$ (as in Taha). The two versions agree only when $n$ is odd: e.g. $n=3,\ m=2$, where both say $D_5\lt0$ for max. Use $(-1)^{m+1}$ and you will never go wrong.

These conditions are sufficient, not necessary

If a required minor comes out $0$, or the signs match neither pattern, the test is inconclusive. It does not prove "neither max nor min". If $f$ is convex (concave) and the constraints are linear, the stationary point is a global min (max) anyway.

6.5The complete procedure (exam template)

1. Lagrangian. Write each constraint as $h_i=g_i-b_i=0$. Form $L=f-\sum\lambda_ih_i$.
2. Necessary conditions. Write out $\partial L/\partial x_j=0$ and $\partial L/\partial\lambda_i=0$. Solve for $(x_0,\lambda_0)$.
3. Bordered Hessian. Border = constraint coefficients. Inside = Hessian of $L$ (= Hessian of $f$ for linear constraints).
4. Sufficient condition. Identify $n$, $m$, and which minors to check (orders $2m+1\dots m+n$). Compute them and apply the sign rule.
5. Conclude. State "max" or "min", give $x_0$ and $z$, and check $x_0\ge0$ if the problem requires it.

Determinant shortcuts

  • Expand along a row or column with many zeros. The bordered Hessian's first row starts with $0$.
  • Row operations $R_i\to R_i-kR_j$ don't change the determinant. Use them to create zeros in a column before expanding (see the 5×5 calculations in §9.2).
  • 3×3 bordered formula: $\begin{vmatrix}0&a&b\\a&p&q\\b&q&r\end{vmatrix}=-(a^2r-2abq+b^2p)$.
  • One constraint, diagonal Hessian $V=\operatorname{diag}(v_1,\dots,v_n)$ with border $(u_1,\dots,u_n)$: $D_{n+1}=-\sum_i u_i^2\prod_{j\ne i}v_j$. Use it to double-check your expansion.

7Inequality constraints: the Karush–Kuhn–Tucker (KKT) conditions

Constraints like $2x_1+x_2\le10$ are the realistic ones (budgets, capacities). KKT extends Lagrange to handle them.

7.1The key idea: is the constraint active or not?

At the optimum, an inequality constraint $g(x)\le b$ is in exactly one of two situations:

One equation captures both situations, complementary slackness:

$$\lambda\,\big(g(x)-b\big)=0\qquad\Longleftrightarrow\qquad\text{either }\lambda=0\ \text{(inactive) or } g(x)=b\ \text{(active)}.$$

(The textbook derives this by adding a squared slack, $g(x)+S^2=b$, and applying Lagrange to $L=f-\lambda(g+S^2-b)$. The extra condition $\partial L/\partial S=-2\lambda S=0$ says "$\lambda=0$ or $S=0$", which is the same thing.)

7.2The KKT conditions

KKT necessary conditions Maximisation, "≤" constraints

For $\ \max f(x)\ $ s.t. $\ g_i(x)\le b_i,\ i=1,\dots,m$:

$$\begin{aligned} &(1)\ \ \nabla f=\sum_{i=1}^m\lambda_i\nabla g_i &&\text{(stationarity)}\\ &(2)\ \ \lambda_i\ge0 &&\text{(sign of multipliers)}\\ &(3)\ \ g_i(x)\le b_i &&\text{(feasibility)}\\ &(4)\ \ \lambda_i\big(g_i(x)-b_i\big)=0 &&\text{(complementary slackness)} \end{aligned}$$

KKT necessary conditions Minimisation, "≥" constraints

For $\ \min f(x)\ $ s.t. $\ g_i(x)\ge b_i,\ i=1,\dots,m$, the conditions have the same form: $\ \nabla f=\sum\lambda_i\nabla g_i,\ \ \lambda_i\ge0,\ \ g_i(x)\ge b_i,\ \ \lambda_i(g_i(x)-b_i)=0.$

ProblemPut every constraint in the formMultiplier sign

Minimisation$g_i(x)\ge b_i$ (multiply a "≤" constraint by $-1$)$\lambda_i\ge0$
Any, with an equality constraint$g_i(x)=b_i$$\lambda_i$ unrestricted
Always convert first: a maximisation NLPP needs all constraints as "≤", and a minimisation NLPP needs all as "≥". Only then are all the $\lambda_i\ge0$.

Why must $\lambda\ge0$? As in 6.2, $\lambda=\partial z^*/\partial b$. In a max problem with $g\le b$, raising $b$ enlarges the feasible region, so the best value can't go down: $\lambda\ge0$. In a min problem with $g\ge b$, raising $b$ shrinks the region, so the minimum can't go down either: $\lambda\ge0$. That is why each problem type is paired with its own constraint direction.

What about x ≥ 0?

The class method (and the textbook) leaves the non-negativity restrictions out of the KKT equations. You solve, and then check that the answer has $x\ge0$. This works in nearly every exam problem. If a candidate has a negative component, or no case survives, treat each $x_j\ge0$ as an extra constraint ($-x_j\le0$ for a max, $x_j\ge0$ for a min) with its own multiplier. Tutorial Q7 is an example where this matters.

7.4Sufficiency of the KKT conditions

Theorem When KKT is enough

  • Maximisation of $f$ s.t. $g_i(x)\le b_i$: if $f$ is concave and every $g_i$ is convex, the KKT conditions are also sufficient. Any KKT point is a global maximum.
  • Minimisation of $f$ s.t. $g_i(x)\ge b_i$: if $f$ is convex and every $g_i$ is concave, any KKT point is a global minimum.
  • If $f$ is strictly concave (convex), that optimum is unique.

Linear constraints are both convex and concave (Hessian $=0$, which is both PSD and NSD), so with linear constraints you only need to check $f$: concave for a max, convex for a min.

"Optimize …" problems: max or min?

When the question just says "optimize", find the Hessian of $f$ first. If $f$ is concave, it's a maximisation problem: set up "≤" KKT, and a KKT point is the global max. If $f$ is convex, it's a minimisation problem. A concave $f$ has no meaningful minimum here (it runs off to $-\infty$ or sits at a corner), so the question can only mean max.

When sufficiency fails

If $f$ is not concave (for a max) or not convex (for a min), a KKT point might not be the optimum. Compare candidate values directly, e.g. at the corner points. See PYQ 2024 Q5b (maximising a convex function) and Tutorial Q7.

8Convex programming, constraint qualification & QPP

Three short topics that explain why everything in §7 works for exam problems.

8.1Convex programming problems

Definition Convex programming problem

A special class of NLP with one of these two forms:

  • $\min f(x)$ s.t. $g_i(x)\ge b_i$ (i.e. $g_i(x)-b_i\ge0$), where $f$ is convex and each $g_i$ is concave;
  • $\max f(x)$ s.t. $g_i(x)\le b_i$ (i.e. $g_i(x)-b_i\le0$), where $f$ is concave and each $g_i$ is convex.

Theorem The feasible region is convex

  • If $g_1,\dots,g_m$ are convex functions, then $S=\{x: g_i(x)\le0,\ i=1..m\}$ is a convex set.
  • If $g_1,\dots,g_m$ are concave functions, then $S=\{x: g_i(x)\ge0,\ i=1..m\}$ is a convex set.

Why (first statement): take $x,u\in S$. By convexity $g_i(\lambda x+(1-\lambda)u)\le\lambda g_i(x)+(1-\lambda)g_i(u)\le\lambda\cdot0+(1-\lambda)\cdot0=0$, so the in-between point is in $S$ too. The second statement follows by applying this to $-g_i$.

So a convex programming problem optimises the "right" kind of function (bowl for min, dome for max) over a convex region. That buys two guarantees:

  1. Every local optimum is a global optimum. There are no false peaks to get stuck on.
  2. The KKT conditions are sufficient. Any KKT point is the global optimum (under a constraint qualification, they are also necessary).

Connect the dots

The "sufficiency of KKT" theorem in 7.4 is exactly the statement "for a convex programming problem, KKT points are global optima". Every PYQ KKT problem with a concave objective and linear constraints is a convex programming problem.

8.2Basic constraint qualification

KKT conditions are called necessary, but that needs a fine-print condition. There are NLPs where the true optimum does not satisfy KKT. These are called ill-behaved problems.

Definition Constraint qualification (CQ)

A constraint qualification is a mathematical condition on the constraints of an NLP which, when satisfied, guarantees that the KKT conditions are necessary at every optimum.

The most commonly used ones:

  • Linear constraints: if all constraints are linear, KKT is always necessary. This covers every exam problem.
  • Linear independence (LICQ): the gradients $\nabla g_i(x^*)$ of the constraints that are active at $x^*$ are linearly independent.
  • Slater's condition (for convex problems): there is a point that satisfies every inequality constraint strictly.
An ill-behaved problem (Kuhn & Tucker's example)

$\max\ x_1\quad$ s.t. $\ x_2-(1-x_1)^3\le0,\ \ -x_2\le0.$

Feasibility needs $0\le x_2\le(1-x_1)^3$, so $x_1\le1$. The optimum is clearly $x^*=(1,0)$. Both constraints are active there, with gradients $\nabla g_1=(3(1-x_1)^2,\,1)=(0,1)$ and $\nabla g_2=(0,-1)$. These point in opposite directions, so they are linearly dependent and LICQ fails. KKT would need $(1,0)=\lambda_1(0,1)+\lambda_2(0,-1)=(0,\lambda_1-\lambda_2)$, which is impossible. The optimum is not a KKT point.

8.3Quadratic programming problem (QPP)

Definition Quadratic programming problem

An NLPP with a quadratic objective and linear constraints. Let $x,c\in\mathbb R^n$ and let $Q$ be a symmetric real $n\times n$ matrix. Then $$\max\ f(x)=c^{T}x+\tfrac12x^{T}Qx\qquad\text{s.t.}\qquad Ax\le b,\quad x\ge0$$ is the general QPP. The term $x^{T}Qx$ is a quadratic form.

How to read off $c$ and $Q$: the Hessian of $f$ is exactly $Q$, so build $Q$ with the shortcut of 4.1 ($2\times$ the coefficient of $x_i^2$ on the diagonal, the coefficient of $x_ix_j$ off the diagonal). $c$ is the vector of linear coefficients.

Example

$f=2x_1+3x_2-x_1^2-2x_2^2$ (Example 2 of §7.5): $\ c=\begin{bmatrix}2\\3\end{bmatrix},\ Q=\begin{bmatrix}-2&0\\0&-4\end{bmatrix}$. Check: $\tfrac12x^{T}Qx=\tfrac12(-2x_1^2-4x_2^2)=-x_1^2-2x_2^2$ ✓.

Key facts about QPP

  • $f$ is concave ⇔ $Q$ is negative semi-definite. Then the QPP (max, linear constraints) is a convex programming problem, and the KKT point is the global maximum. For a min-QPP you need $Q$ PSD.
  • The KKT stationarity condition $c+Qx=A^{T}\lambda$ is linear in $x$ and $\lambda$. So every case of the case method is a system of linear equations, which is why the hand calculations in §7 were so clean.

Look back: every KKT problem in these notes and in the PYQs is a QPP. Whenever $Q$ had the "right" sign (NSD for a max, PSD for a min), the KKT point was automatically the global optimum. The two problems where extra care was needed, PYQ 2024 Q5b (max with $Q$ PSD) and Tutorial Q7 (min with $Q$ indefinite), are exactly the ones where $Q$ has the wrong sign.

(i) Model answer.

Let $S\subseteq\mathbb R^n$ be a convex set and $f:S\to\mathbb R$.

  • $f$ is convex if $f(\lambda x+(1-\lambda)u)\le\lambda f(x)+(1-\lambda)f(u)$ for all $x,u\in S$, $\lambda\in[0,1]$. Examples: $x^2$, $e^x$, $|x|$.
    Geometrically: the chord joining any two points of the graph lies on or above the graph. Equivalently, the graph lies above every tangent line. It is bowl-shaped (∪).
  • $f$ is concave if $f(\lambda x+(1-\lambda)u)\ge\lambda f(x)+(1-\lambda)f(u)$ for all $x,u\in S$, $\lambda\in[0,1]$. Examples: $-x^2$, $\log x$ ($x>0$), $\sqrt{x}$.
    Geometrically: every chord lies on or below the graph, and every tangent lies above it. It is dome-shaped (∩).

Draw the two sketches from §2.2/§2.3, marking $x$, $u$, the chord, and LHS vs RHS.

(ii) $f(x,y)=ax^2+2bxy+cy^2+d$.

1

$f_x=2ax+2by,\ f_y=2bx+2cy$, so $H=\begin{bmatrix}2a&2b\\2b&2c\end{bmatrix}$. This is constant, so its definiteness decides convexity on all of $\mathbb R^2$.

2

Convex ⇔ $H$ PSD ⇔ all principal minors $\ge0$: $2a\ge0,\ 2c\ge0,\ 4ac-4b^2\ge0$, i.e. $$a\ge0,\quad c\ge0,\quad ac-b^2\ge0.$$ Strictly convex if $a>0$ and $ac-b^2>0$ (then $c>0$ automatically).

3

Concave ⇔ $H$ NSD ⇔ odd-order minors $\le0$, even-order $\ge0$: $$a\le0,\quad c\le0,\quad ac-b^2\ge0.$$ Strictly concave if $a\lt0$ and $ac-b^2>0$.

4

$d$ can be any real number: a constant does not affect the Hessian. If $ac-b^2\lt0$, $f$ is neither (saddle-shaped). If $a=b=c=0$, $f=d$ is both.

Convex iff $a\ge0,\ c\ge0,\ ac\ge b^2$. Concave iff $a\le0,\ c\le0,\ ac\ge b^2$. $d$ arbitrary in both cases.

Definition. Let $S\subseteq\mathbb R^n$ be convex. $f:S\to\mathbb R$ is concave if $f(\lambda x+(1-\lambda)u)\ge\lambda f(x)+(1-\lambda)f(u)$ for all $x,u\in S,\ \lambda\in[0,1]$. The chord lies below the graph. Example: $-x^2$.

1

Necessary condition: $\nabla f=\begin{bmatrix}2x_1-4\\2x_2-8\\2x_3-12\end{bmatrix}=\mathbf0\Rightarrow x^*=(2,4,6)$.

2

Sufficient condition: $H_f=\begin{bmatrix}2&0&0\\0&2&0\\0&0&2\end{bmatrix}$, $\ \Delta_1=2,\ \Delta_2=4,\ \Delta_3=8$, all $>0$, so PD everywhere. $f$ is strictly convex and $x^*$ is the global minimum.

3

$f(2,4,6)=4+16+36-8-32-72+56=0$. There is no maximum ($f\to\infty$ as $|x|\to\infty$).

Global minimum at $(2,4,6)$ with $f_{\min}=0$. No maximum exists.

Sanity check by completing squares: $f=(x_1-2)^2+(x_2-4)^2+(x_3-6)^2\ge0$.

Q2. Min $3x_1^2+x_2^2+2x_1x_2+6x_1+2x_2$ s.t. $2x_1-x_2=4$, $x\ge0$Watch the non-negativity condition.

Lagrange. $L=f-\lambda(2x_1-x_2-4)$: $\ 6x_1+2x_2+6=2\lambda$, $\ 2x_2+2x_1+2=-\lambda$. Eliminating $\lambda$: $5x_1+3x_2+5=0$. With $x_2=2x_1-4$ this gives $x_1=\tfrac7{11},\ x_2=-\tfrac{30}{11}$, $\lambda=\tfrac{24}{11}$.

Bordered Hessian: $D_3=\begin{vmatrix}0&2&-1\\2&6&2\\-1&2&2\end{vmatrix}=-22\lt0$ ⇒ min, $z=\tfrac{39}{11}$. But $x_2=-\tfrac{30}{11}\lt0$ violates $x_2\ge0$!

Fix. On the constraint line, $x_2=2x_1-4\ge0$ needs $x_1\ge2$. Substituting, $f=11x_1^2-14x_1+8$, which is increasing for $x_1\ge\tfrac7{11}$. So the minimum over $x_1\ge2$ is at $x_1=2$, $x_2=0$.

With $x\ge0$: $x^*=(2,0)$, $z_{\min}=24$. (Without the sign restriction it would be $(\tfrac7{11},-\tfrac{30}{11})$ with $z=\tfrac{39}{11}$.)

The textbook (Problem 25.08) states this as "Maximize". Since $H_f=\begin{bmatrix}6&2\\2&2\end{bmatrix}$ is PD, $f$ is convex and has no finite maximum along the line. The tutorial's "Min" is the sensible version.

Q3. Max $5x_1+x_2-(x_1-x_2)^2$ s.t. $x_1+x_2=4$

$\partial L/\partial x_1:\ 5-2(x_1-x_2)=\lambda$, $\ \partial L/\partial x_2:\ 1+2(x_1-x_2)=\lambda$. Equate: $x_1-x_2=1$. With $x_1+x_2=4$: $x_1=\tfrac52,\ x_2=\tfrac32$, $\lambda=3$.

$H_f=\begin{bmatrix}-2&2\\2&-2\end{bmatrix}$, so $D_3=\begin{vmatrix}0&1&1\\1&-2&2\\1&2&-2\end{vmatrix}=8>0$ ⇒ max ($n=2,\ m=1$).

$x^*=(\tfrac52,\tfrac32)$, $z_{\max}=12.5+1.5-1=13$.

Q7. Min $2x_1^2+12x_1x_2-7x_2^2$ s.t. $2x_1+5x_2\le98$, $x\ge0$ (KKT)The objective is indefinite: a lesson in when KKT is not enough.

Nature of $f$: $H_f=\begin{bmatrix}4&12\\12&-14\end{bmatrix}$, $\det=-200\lt0$, so indefinite. $f$ is neither convex nor concave, and KKT points are only candidates.

KKT (min, so write the constraint as $-2x_1-5x_2\ge-98$): $\ 4x_1+12x_2=-2\lambda,\ \ 12x_1-14x_2=-5\lambda$.

  • $\lambda=0$: $(0,0)$, $z=0$. A KKT point, but along $x_1=0$, $f=-7x_2^2\lt0$, so it is not a minimum (it is a saddle).
  • $\lambda>0$: $2x_1+5x_2=98$ and $x_1=22x_2$ give $(44,2)$, but $\lambda=-100\lt0$. Rejected.

Include the non-negativity constraints (§7.2). Check the boundary of the triangle $(0,0),(49,0),(0,19.6)$. On $x_2=0$: $f=2x_1^2\ge0$. On $x_1=0$: $f=-7x_2^2$, smallest at $x_2=19.6$. On the slanted edge: $f=4802+98x_2-24.5x_2^2$ (concave), smallest at an end. The minimum is at $(0,\tfrac{98}{5})$. With $x_1\ge0$ active, the KKT multipliers are $\lambda=54.88\ge0$ and $\mu=344.96\ge0$ ✓.

$x^*=(0,\,19.6)$, $z_{\min}=-7(19.6)^2=-\tfrac{67228}{25}=-2689.12$.

A common wrong answer

If you get $(44,2)$ with $z=4900$, you used the max-form sign convention ($\nabla f=\lambda\nabla g$ with $g\le b$) for a min problem. $(0,0)$ already gives a smaller value, $0\lt4900$. In fact $(44,2)$ is the maximum of $f$ along the line $2x_1+5x_2=98$.

11Cheat sheet & common mistakes

Everything on one screen for last-minute revision.

Convexity

  • Convex: $f(\lambda x+(1-\lambda)u)\le\lambda f(x)+(1-\lambda)f(u)$. Chord above, ∪.
  • Concave: $\ge$. Chord below, ∩.
  • 1 variable: $f''\ge0$ ⇔ convex, $f''\le0$ ⇔ concave.
  • $n$ variables: $H$ PSD ⇔ convex, $H$ NSD ⇔ concave.
  • Both ⇔ linear. Sum/positive multiple keeps type. max of convex is convex, min of concave is concave.

Definiteness (symmetric A)

  • PD: all leading minors $>0$.
  • ND: leading minors $-,+,-,\dots$
  • PSD: all principal minors $\ge0$.
  • NSD: odd-order $\le0$, even-order $\ge0$ (all principal).
  • 2×2 with $\det\lt0$ ⇒ indefinite.
  • Eigenvalues: all $>0$ PD, all $\ge0$ PSD, all $\lt0$ ND, all $\le0$ NSD.

Unconstrained

  • 1 var: $f'=0$. $f''>0$ min, $\lt0$ max, $=0$: higher derivatives (odd order ⇒ inflection, even order ⇒ sign decides).
  • $n$ var: $\nabla f=0$. $H$ PD ⇒ min, ND ⇒ max, indefinite ⇒ saddle.
  • Convex everywhere ⇒ global min. Concave ⇒ global max.

Lagrange (equality)

  • $L=f-\sum\lambda_i(g_i-b_i)$, $\nabla L=0$ ($n+m$ equations), $\lambda$ any sign.
  • $H^B=\begin{bmatrix}O&U\\U^T&V\end{bmatrix}$, check orders $2m+1\dots m+n$ ($n-m$ minors).
  • Min: all have sign $(-1)^m$.
  • Max: alternate, starting $(-1)^{m+1}$.
  • $m=1$: min all $\lt0$. Max $D_3>0,D_4\lt0,\dots$
  • $n=3,m=2$: $|H^B|>0$ min, $\lt0$ max.

KKT (inequality)

  • Max ⇒ all constraints "≤". Min ⇒ all "≥".
  • $\nabla f=\sum\lambda_i\nabla g_i$, $\lambda_i\ge0$, feasibility, $\lambda_i(g_i-b_i)=0$.
  • $2^m$ cases. Reject if any $\lambda_i\lt0$, any constraint violated, or $x\not\ge0$.
  • Sufficient: max with $f$ concave and $g_i$ convex. Min with $f$ convex and $g_i$ concave. Linear constraints always qualify.

Convex prog. / CQ / QPP

  • Convex prog.: min convex $f$ s.t. concave $g\ge b$, or max concave $f$ s.t. convex $g\le b$. Local = global, KKT sufficient.
  • CQ: a condition on the constraints making KKT necessary (linear constraints, LICQ, Slater).
  • QPP: $\max c^Tx+\tfrac12x^TQx$, $Ax\le b$, $x\ge0$. Concave ⇔ $Q$ NSD.

Common mistakes that cost marks

  1. Testing semi-definiteness with leading minors only. PSD/NSD need all principal minors.
  2. Wrong bordered-Hessian rule. Remember "min ⇒ sign $(-1)^m$, max ⇒ start $(-1)^{m+1}$", and check only the last $n-m$ minors. Don't use the $(-1)^{m+n}$ typo.
  3. Not converting constraints before KKT. Max needs "≤", min needs "≥". Otherwise you accept or reject the wrong cases (Tut Q7).
  4. Accepting a case after only checking $\lambda\ge0$. Also check that the inactive constraints are satisfied and that $x\ge0$.
  5. Calling a KKT point "global optimum" without checking concavity/convexity of $f$. One line with the Hessian is enough, and it is worth marks.
  6. Hessian of a cross term. $c\,x_ix_j$ puts $c$ (not $2c$, not $c/2$) in positions $(i,j)$ and $(j,i)$. $a\,x_i^2$ puts $2a$ on the diagonal.
  7. Determinant slips. Re-check with the shortcuts in §6.5, or row-reduce before expanding.
  8. Forgetting to state the final value. Always end with $x^*$, the multipliers, $z^*$, and "max" or "min".
