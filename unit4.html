1What is an integer programming problem?

An LPP in which some or all of the variables are only allowed to take whole-number values.

1.1Definition & types

In an ordinary LPP the variables can take any value, such as $x_1 = 2.37$. In many real problems that makes no sense: you cannot build 2.37 machines, hire 4.6 workers or send half a truck. When we add the condition "these variables must be integers", the LPP becomes an integer programming problem (IPP).

Definition Integer programming problem

$$\text{Max (or Min) } Z = c_1x_1 + \dots + c_nx_n$$ $$\text{subject to}\quad a_{i1}x_1 + \dots + a_{in}x_n \;(\le, =, \ge)\; b_i,\qquad x_j \ge 0,$$ $$\text{and } x_j \text{ is an integer for some or all } j.$$
TypeWhich variables are integer?Example
Pure (all-integer) IPPAll of themNumber of chairs and tables to make
Mixed IPP (MILP)Only some; the rest are continuousNumber of trucks (integer) and litres of fuel (continuous)
0–1 (binary) IPPIntegers restricted to 0 or 1Build a warehouse here: yes (1) or no (0)

1.2Why not just solve the LP and round?

It is tempting to ignore the integer condition, solve the LP by simplex, and round the answer. That can go wrong in two ways:

  1. The rounded point may be infeasible. In Tutorial Q3, the LP optimum is $(3.5,\,3.5)$. Rounding up to $(4,4)$ gives $-3(4)+7(4) = 16 > 14$, so it breaks a constraint.
  2. The rounded point may be far from optimal. Take Max $Z = x_1 + 5x_2$ subject to $x_1 + 10x_2 \le 20$, $x_1 \le 2$, with $x_1, x_2$ integer. The LP optimum is $(2,\,1.8)$ with $Z = 11$. Rounding down gives $(2,1)$ with $Z = 7$. But the true integer optimum is $(0,2)$ with $Z = 10$: a completely different corner.

So we need methods that guarantee the best integer point. This unit teaches two: Gomory's cutting plane method (§4–§6), which adds extra constraints ("cuts") until the LP optimum becomes an integer point, and branch and bound (§7), which splits the problem into smaller ones.

1.3The LP relaxation and why it gives a bound

Definition LP relaxation

The LP obtained by dropping the integer conditions from an IPP.

Every integer-feasible point is also feasible for the relaxation, so the relaxation can only do as well or better:

Rule Bounding property

For a Max problem: $Z_{\text{IP}} \le Z_{\text{LP}}$. For a Min problem: $Z_{\text{IP}} \ge Z_{\text{LP}}$. If the LP optimum happens to be an integer point, it is also the IP optimum and you can stop immediately.

Memory hook

Relaxing = more freedom = never worse. Adding a rule (integrality, or a cut) can only make the best value worse or keep it equal. You will see Z drop after every Gomory cut in a Max problem, e.g. 7/3 → 2 in the example of §4.4.

2Formulating integer programs

"Introduction and formulation" is in the syllabus, and the 2022 paper asked for two formulations. The trick is always the same: an integer or 0–1 variable that "switches" something on or off.

2.1Integer quantities

Formulate exactly as in Unit 1 (decision variables, objective, constraints). Then add one line saying which variables must be integers.

Example

A workshop makes chairs (profit Rs 30 each) and tables (Rs 70 each). A chair needs 2 h of carpentry and 1 h of painting; a table needs 3 h of carpentry and 3 h of painting. 18 h of carpentry and 12 h of painting are available. How many of each should be made?

Let $x_1$ = number of chairs, $x_2$ = number of tables.

$$\text{Max } Z = 30x_1 + 70x_2 \quad\text{s.t.}\quad 2x_1 + 3x_2 \le 18,\;\; x_1 + 3x_2 \le 12,\;\; x_1, x_2 \ge 0 \text{ and integers.}$$

2.2Yes/no decisions with 0–1 variables

For a decision "do it or not", use $y \in \{0,1\}$: $y = 1$ means yes. Writing "$0 \le y \le 1$, $y$ integer" means the same thing.

Example: capital budgeting

Four projects have net present values 12, 9, 15, 7 (lakh Rs). Year-1 costs are 5, 3, 7, 2 (budget 12) and year-2 costs are 2, 4, 3, 1 (budget 7). Which projects should be chosen?

$$\text{Max } Z = 12y_1 + 9y_2 + 15y_3 + 7y_4$$ $$\text{s.t.}\quad 5y_1 + 3y_2 + 7y_3 + 2y_4 \le 12,\qquad 2y_1 + 4y_2 + 3y_3 + y_4 \le 7,\qquad y_j \in \{0, 1\}.$$

Logical conditions between yes/no decisions become simple linear constraints:

Condition in wordsConstraint
At most $k$ of the projects$y_1 + y_2 + \dots + y_n \le k$
At least $k$ of the projects$y_1 + \dots + y_n \ge k$
Exactly one of them$y_1 + \dots + y_n = 1$
1 and 2 are mutually exclusive$y_1 + y_2 \le 1$
2 can be chosen only if 1 is chosen$y_2 \le y_1$
1 and 2 together or not at all$y_1 = y_2$

2.3Either–or constraints, "k of m" constraints, if–then

Sometimes only one of two constraints needs to hold. An LP cannot say "or", but a 0–1 variable together with a very large number $M$ can switch a constraint off:

Rule Either $g_1(x) \le b_1$ or $g_2(x) \le b_2$

$$g_1(x) \le b_1 + My,\qquad g_2(x) \le b_2 + M(1-y),\qquad y \in \{0,1\}.$$

If $y = 0$: the first constraint is enforced and the second becomes $g_2 \le b_2 + M$, which is always true (switched off). If $y = 1$: the other way round. Either way at least one of them holds.

Rule At least $k$ of $m$ constraints $g_i(x) \le b_i$ must hold

$$g_i(x) \le b_i + My_i\quad (i = 1,\dots,m),\qquad y_1 + \dots + y_m = m - k,\qquad y_i \in \{0,1\}.$$

$y_i = 1$ means "constraint $i$ is allowed to fail". At most $m - k$ of them may fail, so at least $k$ hold. (Writing $\le m-k$ is equally correct.)

Memory hook

$+My$ switches a constraint off when $y = 1$. "If–then" is just either–or in disguise: "if $g_1 > b_1$ then $g_2 \le b_2$" means the same as "$g_1 \le b_1$ or $g_2 \le b_2$".

$M$ must be large enough that $b_i + M$ can never be reached. In the exam just write "$M$ is a very large positive number".

The 2022 paper (Q4a) asked exactly this. Its full solution is in §9.

2.4Fixed-charge (set-up) costs

Producing product $j$ costs a fixed set-up charge $K_j$ if you make any at all, plus $c_j$ per unit. So cost $= K_j + c_jx_j$ if $x_j > 0$, and $0$ if $x_j = 0$. That jump at 0 is not linear. Fix it with a 0–1 variable $y_j$:

Rule Fixed charge

$$\text{cost} = K_jy_j + c_jx_j,\qquad x_j \le My_j,\qquad y_j \in \{0,1\}.$$

If you produce ($x_j > 0$), then $x_j \le My_j$ forces $y_j = 1$ and you pay $K_j$. If you don't produce, the objective (minimising cost or maximising profit) automatically chooses $y_j = 0$. In place of $M$ you can use any known upper limit on $x_j$.

A variation (2022 Q4b): the fixed cost depends on which range the total labour falls in. You use one 0–1 variable per range and allow at most one of them to be 1. The full solution is in §9.

2.5Other tricks

  • A variable can only take listed values, e.g. capacity $x \in \{10, 20, 50\}$: write $x = 10y_1 + 20y_2 + 50y_3$ with $y_1 + y_2 + y_3 = 1$ and $y_i \in \{0,1\}$.
  • Upper bounds such as $x_1 \le 7$ are ordinary constraints. Keep them; they matter in branch and bound.
  • A binary variable times a continuous one ($xy$) is non-linear. Replace it with $w$ and add $w \le My$, $w \le x$, $w \ge x - M(1-y)$, $w \ge 0$. This is rarely asked, but good to know.

3Toolkit you need first

Gomory's method is "simplex, then add a row, then dual simplex". This section refreshes exactly the pieces of Units 1–2 that it uses, in the same table layout as the lecture video.

3.1The simplex table

Rule Simplex for a Max problem (Zj − Cj form)

  • Columns: $C_B$ (cost of the basic variable), $B$ (the basic variable), $X_B$ (its value), then one column per variable. The $C_j$ row on top holds each variable's cost.
  • Bottom row: $Z_j - C_j = (C_B \cdot \text{column } j) - C_j$, and $Z = C_B \cdot X_B$.
  • Optimal when every $Z_j - C_j \ge 0$ (and every $X_B \ge 0$).
  • Entering variable: the most negative $Z_j - C_j$. Leaving variable: the smallest ratio $X_B / (\text{positive entry in the entering column})$. The pivot is where the two meet.
  • New pivot row = old pivot row ÷ pivot. Every other row = old row − (its entry in the pivot column) × new pivot row.
  • No positive entry in the entering column ⇒ unbounded. At the optimum, if a non-basic variable has $Z_j - C_j = 0$, there may be an alternative optimum.

In the worked solutions below, every pivot step lists the row operations underneath the table. The entering column is shaded blue, the leaving row orange, and the pivot is circled.

3.2Min objectives, ≥ rows and = rows

Min problems. Maximise $Z' = -Z$ instead (change the sign of every cost). At the end, $\text{Min } Z = -(\text{Max } Z')$. All the rules for Max then apply unchanged, including the Gomory and dual simplex rules.

≥ rows. There are two ways to start:

  1. Dual-simplex start (no artificials). If, after converting to Max, every cost $C_j \le 0$ (typical for "Min cost" problems with positive costs), multiply each ≥ row by −1. It becomes a ≤ row with a negative RHS. Add slacks as usual. The first table then has all $Z_j - C_j \ge 0$ but some negative $X_B$, which is exactly the situation the dual simplex method handles.
  2. Big-M. Otherwise, subtract a surplus and add an artificial variable $A_i$ with cost $-M$ (in a Max problem). Run ordinary simplex. When an artificial leaves the basis, delete its column. If an artificial is still basic with a positive value at the optimum, the problem is infeasible.

= rows. Add an artificial variable only (Big-M), as in Unit 1.

In a pure integer problem with integer data, surplus variables are integers too, so the Gomory rules of §4 apply to them like any other variable.

3.3The dual simplex method

Ordinary simplex keeps the table feasible ($X_B \ge 0$) and works towards optimality ($Z_j - C_j \ge 0$). The dual simplex method does the opposite: it keeps the table optimal and works towards feasibility. It is used when every $Z_j - C_j \ge 0$ but some $X_B < 0$.

That is exactly what happens after adding a Gomory cut: the table is still optimal, but the new row has a negative $X_B$. That is why the dual simplex method appears in every Gomory problem, and why the papers sometimes ask for it on its own.

Rule Dual simplex (Max problem, Zj − Cj ≥ 0 throughout)

  1. Leaving row first: the row with the most negative $X_B$.
  2. Entering column: look only at the negative entries $a_{rj}$ of that row. Compute $\dfrac{Z_j - C_j}{a_{rj}}$ (these are all $\le 0$) and take the maximum, i.e. the one closest to zero (smallest in absolute value).
  3. Pivot exactly as in simplex (the pivot is negative).
  4. Repeat until every $X_B \ge 0$. Then the table is optimal and feasible.
  5. If the leaving row has no negative entry, there is no feasible solution (the row says a sum of non-negative terms equals a negative number).

Ties: if two rows are equally negative, or two ratios are equal, you may pick either. These notes take the upper row and the left-most column, as the lecture video does.

Memory hook

Simplex = Column first, then row. Dual simplex = Row first, then column. In simplex the entering column has the most negative Zj−Cj and the pivot is positive. In dual simplex the leaving row has the most negative XB and the pivot is negative. Taking the ratio closest to 0 keeps every Zj−Cj ≥ 0.

The two dual simplex PYQs (Endsem 2025 Q4c, Summer 2026 Q4b) are solved in §9. The first one is an example of "no negative entry", i.e. no feasible solution.

4Gomory's cutting plane method: all-integer problems

Solve the LP, then keep adding one new constraint at a time that slices off the current fractional corner without removing any integer point. Stop when the LP optimum is an integer point.

4.1The idea in one picture

Take Tutorial Q1 (also the lecture video's example): Max $Z = x_1 + x_2$ subject to $3x_1 + 2x_2 \le 5$, $x_2 \le 2$, integers. The LP optimum is the corner $(\tfrac13, 2)$, which is not an integer point. Gomory's method produces the extra constraint ("cut") $x_1 + x_2 \le 2$. That line passes through the integer points $(0,2)$ and $(1,1)$ and slices the fractional corner off. On the smaller region (orange), the LP optimum is an integer point, so we are done.

Definition Cut (cutting plane)

A linear constraint that (i) is violated by the current fractional LP optimum, and (ii) is satisfied by every integer-feasible point. Adding it shrinks the LP region without losing any possible answer.

We don't draw graphs to find cuts; Gomory found a way to read one directly off the optimal simplex table. That is what makes the method work for any number of variables.

4.2Deriving the Gomory (fractional) cut

In the optimal LP table of the example, the $x_1$-row reads (only non-basic variables appear besides $x_1$ itself):

$$x_1 + \tfrac13 s_1 - \tfrac23 s_2 = \tfrac13 .$$

In general, a row of the optimal table whose basic variable $x_B$ has a fractional value $b$ says

$$x_B + \sum_j a_j x_j = b \qquad (x_j \text{ non-basic}).$$

Step 1: split every number into integer part + fractional part. Write $a_j = \lfloor a_j \rfloor + f_j$ and $b = \lfloor b \rfloor + f$, with $0 \le f_j < 1$ and $0 < f < 1$:

$$x_B + \sum_j \lfloor a_j\rfloor x_j - \lfloor b \rfloor \;=\; f - \sum_j f_j x_j .$$

Step 2: look at both sides. If all variables are integers (pure IPP), the left side is an integer. The right side is $f$ minus something non-negative, so it is less than 1. An integer that is less than 1 must be $\le 0$:

$$f - \sum_j f_jx_j \le 0 \quad\Longleftrightarrow\quad \boxed{\;\sum_j f_j x_j \;\ge\; f\;}$$

Step 3: turn it into a table row. Multiply by −1 and add a non-negative Gomory slack $G$:

$$-\sum_j f_j x_j + G = -f .$$

Rule Gomory fractional cut (pure IPP)

From the source row $x_B + \sum a_jx_j = b$:

$$\sum_j f_j x_j \ge f \qquad\text{i.e.}\qquad -\sum_j f_jx_j + G = -f,\quad G \ge 0 .$$

$f_j$ is the fractional part of each coefficient, and $f$ is the fractional part of the RHS.

Why it is a valid cut. (i) At the current LP optimum every non-basic variable is 0, so the left side is $0 < f$: the current point violates the cut and gets sliced off. (ii) Step 2 used nothing but "all variables are integers", so every integer point satisfies the cut.

For the example: $\tfrac13 = 0 + \tfrac13$, $-\tfrac23 = -1 + \tfrac13$, so the cut is $\tfrac13 s_1 + \tfrac13 s_2 \ge \tfrac13$. Substituting $s_1 = 5 - 3x_1 - 2x_2$ and $s_2 = 2 - x_2$ gives exactly $x_1 + x_2 \le 2$, the line in the picture.

Memory hook

"Fractions ≥ Fraction, then Flip and add G." The fractional parts of the row (left) are ≥ the fractional part of the RHS. Then multiply by −1 and add $+G$, which makes the new row's $X_B$ equal to $-f$.

4.3The algorithm, step by step

1. Standard form, ignore integrality. Clear any fractions in the constraints first (§5 case H). Solve the LP by simplex (Big-M or dual simplex if needed: §3.2).
2. Integer test. If every required variable has an integer value in $X_B$ ⇒ stop, optimal.
3. Choose the source row: the basic integer variable with the largest fractional part $f$ (ties: either; we take the upper row).
4. Write the cut $\sum f_j x_j \ge f$, then the row $-\sum f_jx_j + G = -f$.
5. Add the row at the bottom of the optimal table, with $G$ basic and $C_B = 0$. Every $Z_j - C_j$ is unchanged (still $\ge 0$), but $X_B = -f < 0$.
6. Dual simplex until every $X_B \ge 0$. Then go back to step 2.

Each cut makes the LP region smaller, and Gomory proved that (with a sensible choice of source rows) the method finishes after finitely many cuts. In exam problems, 1 or 2 cuts is typical.

4.4Fully worked example (Tutorial Q1 = lecture video example)

Max $Z = x_1 + x_2$ subject to $3x_1 + 2x_2 \le 5$, $x_2 \le 2$, $x_1, x_2 \ge 0$ and integers.

Gomory cut 1.

Choosing the source row. Only $x_{1} = \tfrac{1}{3}$ is fractional (fractional part $\tfrac{1}{3}$), so the $x_{1}$-row is the source row.

Write the source row as an equation (only the non-basic variables appear):

$$x_{1} + \tfrac{1}{3}s_{1} - \tfrac{2}{3}s_{2} = \tfrac{1}{3}$$

Split every number into integer part + fractional part (fractional part is always between 0 and 1, so negatives round down):

$$\tfrac{1}{3} = 0 + \tfrac{1}{3},\qquad \tfrac{1}{3} = 0 + \tfrac{1}{3},\qquad -\tfrac{2}{3} = -1 + \tfrac{1}{3}$$

Gomory (fractional) cut: fractional parts of the coefficients × variables ≥ fractional part of the RHS:

$$\tfrac{1}{3}s_{1} + \tfrac{1}{3}s_{2} \;\ge\; \tfrac{1}{3}$$

Multiply by $-1$ (so it becomes a $\le$ row) and add the Gomory slack $G_{1} \ge 0$:

$$-\tfrac{1}{3}s_{1} - \tfrac{1}{3}s_{2} + G_{1} = -\tfrac{1}{3}$$

In terms of the original variables (substitute the slack definitions) this cut is $x_{1} + x_{2} \le 2$: it removes the current fractional corner but no integer point.

Append this row to the optimal table, with $G_{1}$ basic at value $-\tfrac{1}{3}$ (negative, so the table is now infeasible but still optimal): apply the dual simplex method.

Write: standard form → simplex tables to the LP optimum → "x₁ = 1/3 is not an integer" → source row → splitting into integer + fraction → the cut → the new table → dual simplex → final table → "all Zj−Cj ≥ 0, XB ≥ 0 and the restricted variables are integers, hence optimal" → answer. That is exactly the order of the steps above.

A. The LP optimum is already an integer point

Then it is the integer optimum (bounding property, §1.3). Write "all required variables are integers, so the LP optimum is the integer optimum" and stop. Non-basic variables are 0, and 0 is an integer. Examples: Tutorial Q6 and Summer 2026 Q4c as printed.

B. Several fractional variables, and ties between them

Choose the basic integer variable whose value has the largest fractional part (not the largest value). For example, in Summer 2026 Q4c (Max version) the LP gives $x_2 = \tfrac{21}{10}$ ($f = \tfrac1{10}$) and $x_1 = \tfrac65$ ($f = \tfrac15$). The source row is the $x_1$-row, even though $x_2$ is bigger.

Ties are common: Tutorial Q3 and Q4 both end the LP with $x_1 = x_2 = \tfrac72$. Any tied row gives a valid cut. Take the upper one and say so ("tie; choosing the $x_2$-row arbitrarily").

Some textbooks recommend a finer rule: choose the row with the largest $f\,/\sum_j f_j$, which tends to give a "deeper" cut. Either rule is accepted; the answer is the same, only the route differs.

C. Negative coefficients in the source row

Use the "round down" rule of §3.4: $-\tfrac23 = -1 + \tfrac13$, so $f = \tfrac13$, and $-\tfrac1{10} = -1 + \tfrac9{10}$, so $f = \tfrac9{10}$. The cut always has non-negative coefficients on its ≥ side. If you get a negative coefficient in $\sum f_jx_j \ge f$, you have made a mistake.

D. Integer coefficients in the source row

An integer coefficient (1, −1, 2, …) has fractional part 0, so its variable simply does not appear in the cut. Example: Tutorial Q4's source row is $x_1 + s_1 - \tfrac12 s_3 = \tfrac72$. The $s_1$ term drops and the cut is $\tfrac12 s_3 \ge \tfrac12$. This is true only for pure IPPs; in mixed problems the rule is different (§6).

E. More than one cut is needed

After the dual simplex finishes, check integrality again. If something is still fractional, choose a new source row from the new table and repeat. Keep all earlier rows; Gomory slacks $G_1, G_2, \dots$ become ordinary columns. If $G_1$ is non-basic, it can appear in the next source row, and in a pure IPP it is an integer variable, so treat it exactly like any other variable. For example, Tutorial Q3's second cut is $\tfrac17 s_2 + \tfrac37 G_1 \ge \tfrac27$. Tutorial Q3 needs 2 cuts, and Summer 2026 Q4c (Max version) needs 4.

F. Ties inside simplex or dual simplex

  • Entering tie (two equal most-negative $Z_j - C_j$, as in the first table of §4.4): pick either. The final answer is the same.
  • Leaving tie (equal minimum ratios): pick either. The next table will have a 0 in $X_B$ (degenerate), which is fine.
  • Dual simplex ratio tie (the lecture video had $\max(-1,-1)$): pick either; we take the left-most column.

H. Fractions or decimals in the constraints

The argument of §4.2 needs every variable in the source row to be an integer, including the slacks. A slack is an integer only if its constraint has integer coefficients and an integer RHS. For example, $x_1 + 1.5x_2 \le 4.5$ has slack $4.5 - x_1 - 1.5x_2$, which is $1.5$ at the integer point $(0,2)$. So multiply each such row by the LCM of its denominators first: $2x_1 + 3x_2 \le 9$. Its slack is then an integer.

I. Min objective

Maximise $Z' = -Z$. Everything else (simplex, cut, dual simplex) is as for Max. At the end, $\text{Min } Z = -Z'$. Watch the signs: costs become negative, so the $C_j$ row and $C_B$ column contain negative numbers. Example: Endsem 2025 Q4a.

J. ≥ or = constraints

Get to the LP optimum as in §3.2; after that, nothing changes. A Min problem with positive costs and ≥ rows starts directly with the dual simplex method, with no artificial variables:

N. Optional shortcuts and harmless oddities

  • Dropping old cut rows. If a Gomory slack $G_k$ becomes basic again later, its cut is no longer tight and you may delete its row and column to keep the table small. It is optional; keeping it is never wrong.
  • Zero values in $X_B$ (degeneracy) are integers; nothing special happens.
  • Order of the rows in your table does not matter, as long as each row stays with its basic variable.

6.2The mixed-integer Gomory cut

Rule Mixed cut

Source row $x_B + \sum_j a_jx_j = b$, with $x_B$ integer-restricted and $f$ = fractional part of $b$:

$$\sum_{a_j > 0} a_j x_j \;+\; \frac{f}{f-1}\sum_{a_j < 0} a_j x_j \;\ge\; f \qquad\text{i.e.}\qquad -(\text{same left side}) + G = -f .$$

Positive coefficients are kept whole (not reduced to fractional parts). Negative coefficients are multiplied by $\frac{f}{f-1}$, which is negative, so the product is positive: $\frac{f}{f-1}a_j = \frac{f\,|a_j|}{1-f}$.

Why it works (for the curious). Let $t = \sum a_jx_j$. The row says $x_B = b - t$. Since $x_B$ is an integer, $f - t = x_B - \lfloor b\rfloor$ is an integer, so either $f - t \le 0$ or $f - t \ge 1$. If $t \ge f$, then the positive part alone is $\ge t \ge f$. If $t \le f - 1 < 0$, then the negative part is $\le t \le f-1$; multiplying by $\frac{f}{f-1} < 0$ gives $\frac{f}{f-1}\cdot(\text{negative part}) \ge f$. In both cases the left side of the cut (a sum of two non-negative pieces) is $\ge f$. The argument only used $x_j \ge 0$, so it works for continuous variables.

Memory hook

Mixed cut: "Positives stay, Negatives get $\frac{f}{f-1}$." Pure cut: "everything becomes its fractional part". If a mixed source row happens to have only positive, fractional coefficients, both rules give the same cut. That is why the video's first cut looks like a pure cut.

Common mistake

Applying the pure rule in a mixed problem. A coefficient of $\tfrac43$ on a continuous variable must stay $\tfrac43$ (not $\tfrac13$), as in Tutorial Q8. An integer coefficient such as $1$ on a continuous slack must stay $1$ (it does not vanish). The lecture video's second cut drops the $+s_3$ term this way. It still reaches the right answer for that problem, but the correct cut is shown below.

Refinement (optional): if a non-basic variable is itself integer-restricted, you may use a slightly stronger coefficient: $f_j$ if $f_j \le f$, else $\frac{f(1-f_j)}{1-f}$. The simple rule above is always valid and is what these notes use.

6.4Cases specific to mixed problems

  • Integer variables already integer at the LP optimum, even though a continuous variable is fractional ⇒ stop. Tutorial Q6: $x_2$ must be an integer and is 0 at the LP optimum, so no cut is needed.
  • The final answer has a fractional continuous variable, e.g. $x_2 = \tfrac{10}3$ in Tutorial Q7 or $x_1 = \tfrac12$ in Q8. That is correct and expected.
  • A fractional basic variable that is not integer-restricted (a continuous $x_j$ or a slack) is never chosen as a source row, however big its fraction.
  • Fractions in the data need no scaling (unlike case H), because the mixed cut does not need integer slacks.
  • All the other cases of §5 (Min, ≥ rows, ties, several cuts, infeasibility) work exactly the same way.

7Branch and bound

Not named in the syllabus, but asked in Endsem 2024 (Q4b). Instead of cutting the region, split it into two pieces that together contain every integer point, and solve an LP on each piece.

7.1The idea

Suppose the LP optimum has $x_1 = 3.5$. No integer point has $3 < x_1 < 4$, so every integer solution satisfies either $x_1 \le 3$ or $x_1 \ge 4$. Solve two new LPs, one with each extra constraint. This is branching. Each new LP is smaller, and its optimum is again either integer or fractional, so we keep branching and get a tree of subproblems.

To avoid exploring the whole tree, use bounds. The LP value of a node is the best that any integer point below it could achieve (§1.3). Once we hold an integer solution with value $Z^*$ (the incumbent), any node whose LP value is no better than $Z^*$ can be thrown away: it cannot contain anything better.

7.2Rules (Max problem)

Rule Branch and bound

  1. Solve the LP relaxation (node 0). If it is integer, stop.
  2. Branch on a fractional integer variable $x_j = v$, usually the one with the largest fractional part: child A gets $x_j \le \lfloor v\rfloor$, child B gets $x_j \ge \lceil v \rceil$. Each child keeps all constraints of its parent.
  3. Solve the LP of each child. A node is fathomed (not branched further) if:
    • its LP is infeasible, or
    • its LP optimum is integer: it becomes the incumbent if it beats the current one, or
    • its LP value is no better than the incumbent (≤ for Max, ≥ for Min).
  4. Among the nodes still open, branch on the one with the best LP value. When no open node is left, the incumbent is optimal.

Solving each node's LP. With two variables (the usual exam case), solve it graphically: the optimum is at the corner where two constraints are tight, so solve those two equations. With more variables, add the new bound as a row to the parent's optimal table and apply the dual simplex method, just like a Gomory cut.

Min problems: reverse "better" everywhere. Lower Z is better, a node is pruned if its LP value is ≥ the incumbent, and the LP value is a lower bound.

Mixed problems: branch only on integer-restricted variables. A node is "integer" when those variables are integers.

Memory hook

Branch = split at the fraction: "floor on the left, ceiling on the right". Fathom when the node is Infeasible, Integer, or Inferior (the three I's).

Common mistakes

Common mistakes

  • Fractional part of a negative number taken as negative, or as |fraction|.
  • Choosing the source row by the largest value instead of the largest fractional part.
  • Forgetting to multiply the cut by −1 before adding it: then $G$ would need a negative coefficient and cannot start in the basis.
  • In dual simplex: choosing the entering column by the most negative entry instead of by the ratio, or including positive entries.
  • Using the pure cut in a mixed problem (dropping integer coefficients of continuous variables, or reducing $\tfrac43$ to $\tfrac13$).
  • Choosing a continuous variable's row as the source row in a mixed problem.
  • Not scaling a constraint with fractional coefficients in a pure problem (§5 H).
  • Min problems: forgetting to convert back, $\text{Min } Z = -\text{Max } Z'$.
  • Stopping when the table is optimal but not feasible ($X_B < 0$), or feasible but not integer.

Appendix: Q9 and Q10 (duality, Unit 2)

These two questions are on the same sheet but belong to Unit 2. They use the complementary slackness theorem: (a) if a primal constraint is slack (strict inequality) at the optimum, its dual variable is 0; (b) if a primal variable is positive at the optimum, its dual constraint holds with equality.

$y_1 = 0,\ y_2 = 2,\ y_3 = 0$, Min $W = 100 \times 2 = 200 = $ Max $Z$ ✓ (strong duality).

The 1st dual constraint is tight even though $x_1 = 0$. This is the sign of alternative primal optima: the objective $4x_1 + 10x_2$ is parallel to $2x_1 + 5x_2 \le 100$, so other optimal points such as $(12.5, 15)$ exist.

Q10 Duality · equality constraintMax $Z = 5x_1 - 4x_2 + 3x_3$ s.t. $2x_1 + x_2 - 6x_3 = 20$, $6x_1 + 5x_2 + 10x_3 \le 76$, $8x_1 - 3x_2 + 6x_3 \le 50$, $x_1, x_2 \ge 0$. The primal optimum is $x = (\tfrac{55}7, \tfrac{30}7, 0)$, $Z = \tfrac{155}7$. Find the dual solution.

The sheet prints only $x_1, x_2 \ge 0$, but the same LP in Midsem 2024 Q2a has $x_3 \ge 0$ as well, and the given optimum is only optimal under that assumption. So we take $x_3 \ge 0$.

1

Dual. An equality constraint gives an unrestricted dual variable $y_1$; the ≤ rows give $y_2, y_3 \ge 0$:

$$\text{Min } W = 20y_1 + 76y_2 + 50y_3$$ $$\text{s.t.}\quad 2y_1 + 6y_2 + 8y_3 \ge 5,\quad y_1 + 5y_2 - 3y_3 \ge -4,\quad -6y_1 + 10y_2 + 6y_3 \ge 3,$$ $$y_1 \text{ unrestricted},\quad y_2, y_3 \ge 0.$$
2

Primal constraints at the optimum:

  • Row 2: $6\cdot\tfrac{55}7 + 5\cdot\tfrac{30}7 = \tfrac{480}7 < 76 = \tfrac{532}7$: slack ⇒ $y_2 = 0$.
  • Row 3: $8\cdot\tfrac{55}7 - 3\cdot\tfrac{30}7 = \tfrac{350}7 = 50$: tight.
  • Row 1 is an equality: always tight (no condition on $y_1$).
3

$x_1 > 0$ and $x_2 > 0$ ⇒ dual constraints 1 and 2 are equalities (with $y_2 = 0$):

$$2y_1 + 8y_3 = 5,\qquad y_1 - 3y_3 = -4 .$$

From the second, $y_1 = 3y_3 - 4$. Substituting: $6y_3 - 8 + 8y_3 = 5$, so $y_3 = \tfrac{13}{14}$ and $y_1 = \tfrac{39}{14} - \tfrac{56}{14} = -\tfrac{17}{14}$.

Check dual constraint 3 (where $x_3 = 0$, so an inequality is fine): $-6(-\tfrac{17}{14}) + 0 + 6\cdot\tfrac{13}{14} = \tfrac{180}{14} = \tfrac{90}7 \ge 3$ ✓. $y_3 \ge 0$ ✓; $y_1 < 0$ is allowed because $y_1$ is unrestricted.

$y_1 = -\tfrac{17}{14},\ y_2 = 0,\ y_3 = \tfrac{13}{14}$, Min $W = 20(-\tfrac{17}{14}) + 50(\tfrac{13}{14}) = \tfrac{310}{14} = \tfrac{155}7 = $ Max $Z$ ✓.
